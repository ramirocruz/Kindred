# Kindred project memory

This folder is tracked, public repository documentation. It is excluded from the Pages website, not hidden from GitHub.

## Read and update

1. Read [index.md](index.md) and [current.md](current.md).
2. Read only topics relevant to the task. Use source code as the implementation authority.
3. Update facts in place; label **Implemented**, **Verified**, or **Hypothesis**.
4. Skim related older notes for contradictions on every update. Correct stale statements and links; summarize useful history in [archive](archive/README.md).
5. Keep decisions, test evidence and deployment status in their owning files; link instead of duplicating.
6. Commit sanitized notes with the associated changes. Never include secrets, invitation keys, private accounts, signed URLs, raw transcripts or machine-local artifacts.

## Compaction

Compact at milestones, when a decision changes, or when a file exceeds its budget: current 80 lines, index 60, active topics 120, progress latest 10 milestones. Preserve rationale, unresolved work and commit/evidence references, not repeated narratives. Historical summaries never override current requirements.
